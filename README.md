# BuildMyBot.app

The ultimate white-label AI chatbot platform for businesses and agencies. Build, deploy, and resell intelligent bots with zero coding.

## 🚀 Overview

BuildMyBot is an all-in-one AI chatbot platform that allows businesses and agencies to create, deploy, and resell intelligent assistants with no coding required. The platform provides a comprehensive suite of tools for visual bot building, lead management, white-label reselling, AI-powered marketing, and even automated phone agents.

### ✨ Key Features

- **Visual Bot Builder:** No-code interface to design bot personas, define system prompts, and train on your own data (PDFs, URLs, text).
- **Automated Lead CRM:** Automatically capture, score, and manage leads within a built-in pipeline view.
- **Reseller & Agency Portal:** White-label the platform with your own domain, manage clients, and track commissions.
- **24/7 AI Phone Agent:** Deploy an AI receptionist that can answer calls, book appointments, and log transcripts.
- **AI Marketing Studio:** Generate high-quality marketing content, including social media posts, ads, emails, and even entire websites.
- **Bot Template Marketplace:** Browse and install pre-built bot templates for various industries with one click.

### 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Backend:** Supabase (PostgreSQL, Auth, Edge Functions)
- **AI:** OpenAI (GPT-4o/GPT-4o Mini), Google Gemini
